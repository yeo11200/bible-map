# 공생애 여정 설계

## 목표

마태·마가·누가·요한복음의 전체 개역개정 본문을 읽으면서, 예수님의 공생애 주요 장소와 사건을 지도에서 복음서별로 비교한다.

## 사용자 경험

- 홈에는 `예수님의 공생애 여정` 카드 하나를 추가한다.
- 공생애 화면은 `전체 여정`, `마태`, `마가`, `누가`, `요한` 탭으로 시작한다.
- 탭을 바꾸면 해당 복음서에 기록된 장소·사건만 지도와 본문 패널에 표시한다.
- 전체 여정에서는 같은 장소의 병행 본문을 한 카드에 함께 보이며, 복음서별 범례 색으로 기록 범위를 보여 준다.
- 장소 카드에는 설명, 관련 구절, 해당 복음서의 실제 개역개정 구절을 표시한다.
- 본문 리더는 탭에 맞춰 마태 28장, 마가 16장, 누가 24장, 요한 21장을 모두 제공한다.
- 모바일은 기존 접이식 본문 패널과 선택 장소 강조를 유지한다.

## 데이터와 서버

- 원문은 `/Users/jinseop.shin/Downloads/개역개정-한글/신약`의 HWP 원본을 사용한다.
- `scripts/export-gaeokgaejeong.mjs`가 네 복음서를 각각 JSON으로 변환한다.
- `/api/books/gospels`는 탭, 장소·사건, 네 복음서의 전체 장 데이터를 반환한다.
- `/api/books/gospels/map`은 공생애 장소와 이동선을 GeoJSON으로 반환한다.

## 시각 규칙

- 마태: `#984f2a`, 마가: `#3e6d83`, 누가: `#765e9c`, 요한: `#3f7a50`.
- 지도 핀의 기본 색은 사건의 대표 복음서 색을 사용하고, 선택한 탭은 해당 색의 범례와 카드 강조로 명확히 표시한다.
- 전체 여정 탭에서만 병행 본문 기록 복음서를 색상 칩으로 함께 표시한다.

## 범위

- 지도 사건은 공생애의 지리적 흐름을 설명하는 핵심 장소·사건으로 제한한다.
- 전체 본문은 네 복음서의 모든 장·절을 제공한다.
- 복음서 간 정확한 일대일 시간순 조화표를 별도 제공하지 않는다. 동일 장소의 관련 병행 본문만 묶는다.
